¹ 강동윤·임도윤·안지형의 범위 댓글은 작업 후 추가했다. 시작 시점에 있었다고 소급하지 않는다. 이정수 범위 댓글은 담당 PR을 수정하기 전에 추가했다.

각 PR의 리뷰는 단순 댓글이 아닌 `Submit review` 상태로 제출됐고 각 PR은 동료 승인 후 `dev`에 머지됐다. 위 두 개 이상 계정 작성 커밋의 GitHub 작성자·연결 계정은 각각 해당 팀원으로 확인했다. 안지형 PR #12와 이정수 PR #10의 후속 보완 커밋은 이영 계정 작성자로 표시된다. 이영 요청에 따라 Codex가 실제 코드를 실행·수정했고 담당 계정으로 푸시한 사실은 각 PR·`ai_log.md`에 구분해 기록했다. 팀원 본인의 별도 수동 실행은 확인되지 않았다.

AI 역할별 복사용 프롬프트는 `docs/ai_prompts_gangdongyun.md`, `docs/ai_prompts_limdoyun.md`, `docs/ai_prompts_anjihyeong.md`, `docs/ai_prompts_leejeongsu.md`에 있다. 실제 사용한 요청·출력·수정 이유는 `ai_log.md`에만 실제 사용으로 기록했다. 로컬 DART 원본·API 키는 커밋에 포함하지 않았다.
