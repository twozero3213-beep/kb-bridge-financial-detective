# 팀원용 AI 프롬프트와 작업 기록 안내

이 문서는 복사해서 **실제 데이터·컬럼·Issue 번호로 채우는 프롬프트 초안**이다. AI 결과를 그대로 제출하거나 실행하지 않은 검증을 `ai_log.md`에 완료로 적지 않는다. 각자 실제로 사용한 프롬프트, 답변 요약, 실행 명령/셀, 데이터 비교 결과, 채택·수정·폐기 이유를 기록한다. API 키와 원본 데이터 전체를 AI 대화에 붙여넣지 않는다.

직접 확인: 데이터 출처·파일 수·행 수·컬럼·중복 기준을 실제로 실행해 `Issue`와 PR에 적는다.

## 5 공시 Pandas 담당 — 이정수 Issue #7 이번 세션 입력

사용자의 실제 요청은 새 역할 배정을 진행하고, 나중에 도착하는 공통 데이터를 바탕으로 자동 반영할 수 있게 만드는 것이다.

> 공통 DB 경로는 data/processed/dart.sqlite이고 ZIP의 build_db.py에서 확인한 테이블은 disclosures, 필수 컬럼은 corp_code/rcept_no/rcept_dt/report_nm이다. 실제 기업·기간·DB와 나지수님의 SQL은 아직 제공되지 않았다. Issue #7 산출물은 notebooks/analysis_disclosure.ipynb와 src/disclosure_pandas.py다. 월별·제목 유형별 빈도, 전월 대비 변화, 확인 후보 기준과 민감도를 구현한다. 정정·중복·완전한 월 경계를 명시하고, 자체 참조 SQL과 팀 SQL 대조를 분리한다. 나중에 팀 DB·설정·SQL 파일이 같은 경로에 놓이면 재실행으로 읽게 한다. 없는 실제 결과나 GitHub 완료 증거를 만들지 않는다.

위 문단은 이 세션의 실제 입력을 정리한 것이며 별도의 추가 AI 호출을 했다는 뜻이 아니다. 생성한 코드의 실행 결과와 사람의 검증 여부는 ai_log.md에 구분해 기록한다.

실제 데이터 도착 후 보완할 입력: 기업/기간/수집 완료 범위/정정·중복·유형 정책/SQL 파일의 확정 경로. 현재 수치는 합성 테스트에 한정한다.
