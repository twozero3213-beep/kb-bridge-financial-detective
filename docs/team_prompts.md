# 팀원용 AI 프롬프트와 작업 기록 안내

이 문서는 복사해서 **실제 데이터·컬럼·Issue 번호로 채우는 프롬프트 초안**이다. AI 결과를 그대로 제출하거나 실행하지 않은 검증을 `ai_log.md`에 완료로 적지 않는다. 각자 실제로 사용한 프롬프트, 답변 요약, 실행 명령/셀, 데이터 비교 결과, 채택·수정·폐기 이유를 기록한다. API 키와 원본 데이터 전체를 AI 대화에 붙여넣지 않는다.

> `src/dart_fetch.py`로 얻은 로컬 응답 또는 강사 제공 CSV를 검토한다. 기업 식별자, 접수일/사업연도, 금액 단위, 연결/별도, 결측·중복 후보를 확인하는 Python 코드 설계를 제안해 줘. 확인하지 않은 필드는 추측하지 마라. 원본을 바꾸지 않는 전처리 절차와 작은 입력에서도 재현할 검증 항목을 제시해 줘. 내 코드 파일은 [파일]이다.

직접 확인: 데이터 출처·파일 수·행 수·컬럼·중복 기준을 실제로 실행해 `Issue`와 PR에 적는다.

> 이 PR의 Issue·코드·실행 근거는 [링크]다. 실제 스키마와 분석 질문을 기준으로 계산 오류, 기간/단위 혼합, 중복 집계, 검증 누락을 찾아 줘. 확신할 수 없는 부분은 질문으로 남겨 줘. 승인 여부는 내가 코드를 읽고 실행 결과를 확인한 뒤 결정한다.

실제 리뷰어는 GitHub PR에 본인이 확인한 질문·수정 제안·검증 의견을 직접 남긴다. AI의 답변만 붙여넣어 리뷰한 것으로 처리하지 않는다.
