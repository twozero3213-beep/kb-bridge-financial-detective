# 작업별 AI 프롬프트 기록

## 이정수 검증 파트 — 이번 실제 요청

사용자 요청: “이거는 총 프로젝트야. 내가 일단 깃허브 연결해봤고, 이정수 파트만 일단 만들고 싶어. 나중에 유기적으로 연결할 수 있게”

제공된 역할 문맥: src/validation_leejeongsu.py에서 SQL/Pandas 비교, 행 수·중복·결측 검사, 증감률 재계산, 이상값 후보 검증을 PASS/CHECK로 출력한다.
실제 기업·기간·스키마·Issue 번호: 미제공. 저장소도 초기 골격 상태.
산출물: src/validation_leejeongsu.py, tests/test_validation_leejeongsu.py, docs/validation_leejeongsu.md.

### 실제 데이터 도착 후 사용할 후속 초안 (아직 사용 안 함)

기업 [실제 기업], 기간 [시작/종료와 포함 기준], Issue [번호], 원본 [파일/키], SQL 결과 [파일], Pandas 결과 [파일], 집계 키 [컬럼], 비교 지표 [컬럼], 정정/중복 정책 [정책], 증감률 공식 [공식], 후보 임계값 [기준]을 입력으로 독립 검증한다. 불일치 원인과 실행 근거를 기록하고 기업 위험이나 원인은 추측하지 않는다.
