## 계산 기준

공통 SQLite `disclosures`에서 접수번호 하나를 한 건으로 세고, 접수일의 연월과 양쪽 공백을 지운 보고서명으로 집계한다. `[기재정정]`·`[첨부추가]` 접수도 전체 건수에 포함하며 `correction_count`에 따로 센다. 월 합계는 전년 같은 달과 비교한다. 전년 같은 달이 없거나 0건이면 증감률은 `NULL`이다. 후보는 증감률 절댓값 50% 이상이면서 건수 차이 절댓값 10건 이상인 달이다.

```powershell
python -m src.run_disclosure_sql data/processed/dart.sqlite
python -m unittest discover -s tests -v
```

실행기는 원본의 접수번호·날짜·유형을 먼저 검증하고, SQL 뷰와 이정수 Pandas의 회사·연월·보고서명별 건수 및 정정 건수를 비교한다. 월 단위에서는 전년 건수 유무와 후보 값을 먼저 비교하고, 전년 값이 있는 행에서만 증감 건수·증감률을 비교한다. 따라서 양쪽이 모두 비워 둔 전기 없는 행을 거짓 오류로 만들지 않는다.

## 실제 데이터 결과 (2026-09-28)

로컬 Open DART 삼성전자(`00126380`) 2023년 154건·2024년 284건, 총 **438건**에서 기간·유형 **197그룹**, 월 **24개**, 정정·첨부추가 **30건**이다. SQL과 Pandas 비교 36개 항목 모두 `PASS`, 불일치 0건이다. 2024년 기본 기준 후보는 3·6·9·10·11·12월 6개다. 9월은 전년 4건에서 31건(+27건, +675%)이며 12월은 27건에서 43건(+16건, +59.259%)이다. 전체 테스트 27개가 통과했다.

반례 검사에서 전년 같은 달 자료가 없는 회사의 증감률은 양쪽에서 결측으로 맞았지만 기존 비교 함수가 결측을 오류로 처리했다. 비교 대상을 전년 값 유무와 비교 가능한 변화 수치로 나눠 수정했다. 같은 원본의 계산 일치와 탐색용 후보 기준만 확인했으며 기업 위험·이상 원인을 확정하지 않는다.
