## 실행

공통 데이터 적재 코드가 `data/processed/dart.sqlite`를 만든 뒤 저장소 루트에서:

```powershell
python -m src.run_finance_sql data/processed/dart.sqlite 00126380 2024 --fs-div CFS
python -m unittest discover -s tests -v
```

SQL은 사업보고서(`reprt_code=11011`)·원화·회사·연도·연결/별도를 구분한다.
매출액, 영업이익, 당기순이익, 자산총계를 전기와 비교한다. 전기값이 0이면
증감률은 `NULL`이며, 음수이면 분모의 절댓값을 사용한다. 같은 회사·연도·재무제표·
계정명이 중복되면 `ord`가 가장 작은 원본 한 행을 대표로 선택하고 `source_rows`에
원본 개수를 남긴다. 숫자로 읽을 수 없는 금액은 `NULL`로 남겨 품질 점검 쿼리에 보인다.

## 실제 데이터 실행 기록 (2026-09-28)

로컬 Open DART 삼성전자(`00126380`) 사업보고서 2023·2024의 재무 원본 60행에서
선택한 네 지표의 회사·연도·연결/별도별 결과는 16행이다. 2024년 연결(CFS)
네 지표 결과는 다음과 같다. 금액 단위는 원이다.

| 지표 | 2024 당기 | 전기 | 증감률 |
| --- | ---: | ---: | ---: |
| 자산총계 | 514,531,948,000,000 | 455,905,980,000,000 | +12.859% |
| 매출액 | 300,870,903,000,000 | 258,935,494,000,000 | +16.195% |
| 영업이익 | 32,725,961,000,000 | 6,566,976,000,000 | +398.341% |
| 당기순이익(손실) | 34,451,351,000,000 | 15,487,100,000,000 | +122.452% |

전체 16행에서 숫자 변환 실패는 0행이다. 원본 중복 계정 그룹은 4개이며,
2024년 연결 당기순이익은 원본 2행이 같은 금액으로 들어와 대표 1행만 남겼다.
`python -m unittest discover -s tests -v`에서 SQL 테스트 1개가 통과했다.
이 변화만으로 기업 위험이나 원인을 판단하지 않는다. Pandas 담당자의 동일 기준
결과와 비교하고 `dev` 통합 검증을 마쳐야 최종 Q1 결과가 된다.
