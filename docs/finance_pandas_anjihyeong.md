# 안지형 담당: 재무 Pandas 분석

- Issue #6 / 브랜치 `feature/agh3724-finance-pandas`
- 실행 코드: `src/finance_pandas_anjihyeong.py`
- 재현 노트북: `notebooks/analysis_finance.ipynb`
- 반례 검사: `tests/test_finance_pandas_anjihyeong.py`

## 처리 기준

Open DART의 `finance` 테이블에서 사업보고서(`11011`)·원화(`KRW`)의 매출액, 영업이익, 당기순이익, 자산총계를 선택한다. 회사·연도·연결/별도·재무제표 종류·계정 단위로 묶는다. 같은 키의 중복 원본은 `ord`가 가장 작은 행을 대표로 쓰고 `source_rows`에 원본 수를 보존한다. 쉼표가 포함된 금액 문자열을 수치로 변환하고 비숫자는 결측으로 둔다. 증감률은 `(당기-전기)/abs(전기)*100`이며 전기가 0이면 결측이다.

## 재현 방법

저장소 루트에 `data/processed/dart.sqlite`를 준비하고 노트북을 실행한다. DB에는 `finance` 테이블이 있어야 한다. DB 파일은 `.gitignore` 대상이므로 Git에 올리지 않는다. 노트북은 같은 DB에 강동윤 SQL 뷰를 만들고 독립 Pandas 결과를 회사·연도·보고서·CFS/OFS·재무제표 종류·계정 키로 비교한다.

```powershell
python -m unittest discover -s tests -v
jupyter nbconvert --to notebook --execute notebooks/analysis_finance.ipynb --output analysis_finance.executed.ipynb
```

## 실제 실행 기록 (2026-09-28)

로컬 Open DART 삼성전자(`00126380`) 2023·2024 사업보고서 DB의 재무 원본 60행에서 선택 지표 16행을 계산했다. 중복 원본 그룹은 4개다. 2024년 연결(CFS) 네 지표는 다음과 같다. 금액 단위는 원이다.

| 지표 | 2024 당기 | 전기 | 증감률 |
| --- | ---: | ---: | ---: |
| 자산총계 | 514,531,948,000,000 | 455,905,980,000,000 | +12.859% |
| 매출액 | 300,870,903,000,000 | 258,935,494,000,000 | +16.195% |
| 영업이익 | 32,725,961,000,000 | 6,566,976,000,000 | +398.341% |
| 당기순이익(손실) | 34,451,351,000,000 | 15,487,100,000,000 | +122.452% |

강동윤 SQL과 Pandas의 같은 16행은 금액·증감률·중복 수까지 불일치 0건이다. 전체 단위 검사 12개가 통과했다. 반례 검사는 CFS/OFS 분리, 전기 0, 전기 음수, 중복 행, 비숫자 금액을 포함한다. 이 결과는 **같은 로컬 원본에 대한 계산 일치**이며 원본 공시의 진위나 이상징후 원인을 증명하지 않는다.
